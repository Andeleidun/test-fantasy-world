# Content authority

Use [`public/README.md`](public/README.md) for the current public collection and [`public-sync.json`](public-sync.json) for the source snapshot. The reader combines this collection into [five complete guides](../README.md). Its composition, editorial merges, figure placements and source destinations are recorded in `reader/`. The build uses the synchronized public text and these reader files.

Earlier subject articles now link to the current guides and immutable historical versions with their source credits. The article catalog agrees with the current public catalog. Original language ordering, map data and provenance records remain available for old bookmarks and historical research scripts. Those research records may contain superseded claims or material excluded by the current public boundary.
