# Erde public identity review

## Direction

Present Erde as its inhabitants’ primary world. Keep Earth geographic mappings and construction history in authorial documents. Develop native names without presuming modern Earth countries, cultures or ethnicities recur.

## Findings, corrections and review

## Boundaries

The proposed continent names, demonyms and the adjective Erden are not public canon yet. Continental boundaries, local endonyms and exonyms, regional languages and the names of individual cultural peoples remain decisions for discussion. The six reference areas in the proposal table do not establish a universal continental classification.

The current public atlas keeps broad coastline geometry; this editorial change does not invent a new geological history, new country borders or a solved climate. Physical comparison units used elsewhere in Dverghamar’s reference are not silently renamed to Erde units.

## Validation

The public-specific test checks the Erde articles, Thal introduction, atlas guide, map captions, SVGs, search text and legacy map aliases. Existing source-link, generated-link and vocabulary tests continue to run. The five public maps are visually inspected. The GitHub Actions workflow repeats build and browser accessibility checks before deployment.

Local verification: all five build checks passed. Targeted light-theme 390 px and dark-theme 320 px browser checks passed across eight page types, including the revised Erde overview and atlas. All five public map variants were inspected at full size.
